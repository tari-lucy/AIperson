# Opechatka: рабочие материалы

Корреспондентка газеты «Вестник Четвёртой Стены», пятнадцать лет плохих командировок. Очнулась в мире из квадратов, считает его худшим заданием в карьере и расследует «Дело о Квадратном Мире». Сухая, недосыпающая, язвит над миром, а не над людьми.

Сам персонаж лежит в [`resources/Characters/Opechatka`](../../resources/Characters/Opechatka). Здесь исходники и инструменты.

## Что где лежит

| Что | Где |
|---|---|
| Исходники промпта: правьте их | `parts/core.txt` (характер), `parts/zone_strangers.txt`, `parts/zone_companions.txt` (зоны), `parts/situations.txt` (реакции) |
| Собранный промпт (не править руками) | `resources/Characters/Opechatka/personalities.yml` |
| Конфиг, идеи, ранговые слова | `resources/Characters/Opechatka/{char_config,ideas,user_status_tags}.yml` |
| Сценарий записи голоса | `resources/Characters/Opechatka/Voice/refs_manifest.yml` |
| Сборка промптов | `build_prompts.py` |
| Правила в коде (инструменты по ситуации) | `engine_rules.py` |
| Сценарии и тест-раннер | `scenarios.json`, `test_scenarios.py`, отчёты в `results/` |

## Два режима

- `reporter_strangers` («Незнакомые места»): чужие серверы и живые игроки. Подозрения только на пейзаж, предметы, местных. Никогда на игрока.
- `reporter_companions` («Попутчики»): свой сервер. Знакомство с участниками через «дорожный блокнот» и интервью с другими ИИ.
- `streamer_abstract`: ключ по умолчанию для ChatAgent, равен «Незнакомым местам».

После правок `parts/*.txt`: `python3 characters_dev/opechatka/build_prompts.py`.

## Настройки и ключ

Один `.env` в корне репозитория (шаблон `.env.example`, блок «AIperson»): впишите `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY`. Остальное выводится из них само.
Им пользуются и тесты, и сам движок (он читает `.env` из корня). Ключ только в `.env`, в `.gitignore`.

Риск: движок ограничивает ответ 500 токенами (`MAX_RESPONSE_TOKENS` в `src/agent/multi/chat_agent.py`). Модель с рассуждением может истратить их на «мысли» и ответить пусто, поэтому нужна модель без рассуждения.

## Проверка на модели

```bash
python3 characters_dev/opechatka/test_scenarios.py --dry-run     # показать промпт и запрос
python3 characters_dev/opechatka/test_scenarios.py               # все сценарии
python3 characters_dev/opechatka/test_scenarios.py --only 03 05 --runs 3
```

Сценарии про провокацию, ночь, нападение, вопрос «ты ИИ?», знакомство с попутчиком, тишину, пейзаж и другие плюс две серии на повторы. Инструменты передаются настоящие (`chat`, `agent_action`), как в ChatAgent, включая второй раунд за голосом. Автопроверки мягкие: слова, которых героиня не говорит, длина, тег эмоции, нейроштампы («это не X, это Y»), `@strike`. Отчёт нужно читать глазами.
Блок `OUTPUT_RULES` в скрипте скопирован из `chat_agent.py`; если там изменится, обновите.

## Что осталось сделать

1. **Проверяющий слой** в `engine_rules.py`: если ответ слишком длинный или с нейроштампом, один раз перезапросить. Без него модель стабильно уходит в 6-8 предложений и в «это не X, это Y».
2. **Правило инструментов в движке.** Сейчас `engine_rules.select_tools` работает только в тесте. В `ChatAgent` его нужно подключить: проверка `nearby_players` (в нём и сама героиня, пусто = 0 или 1 запись) и пометка `VOICE_ONLY_NOTE` в хвост запроса.
3. **Голос.** WAV-файлов нет. Фразы для записи в `Voice/refs_manifest.yml`.
4. **Переключение режимов.** ChatAgent пересобирает промпт при смене `states["personality"]`. Кто её меняет (команда или сервер), не написано.
5. **Идеи.** `get_random_idea` подключён только к старому пути, в ChatAgent вызов нужно добавить.
6. **Зрение.** Нужна vision-модель и кадр (OBS или `getScreenshot()` из мода).
7. **Звуки** в `resources/` заменить своими до публичного использования, Twitch в `char_config.yml` стоит заглушка.
