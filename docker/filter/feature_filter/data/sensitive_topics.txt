# ОПАСНЫЕ ТЕМЫ — персонаж их не обсуждает вообще.
#
# ЗАЧЕМ ЭТОТ ФАЙЛ
#
# Персонаж работает в прямом эфире на публичную аудиторию, и всё, что он
# скажет, сказано от лица владельца канала. Разговор на темы ниже создаёт
# не «неловкость», а прямой юридический риск: пропаганда нетрадиционных
# отношений, дискредитация вооружённых сил, разжигание межнациональной
# и религиозной розни, оправдание терроризма и экстремизма, пропаганда
# наркотиков и суицида — по каждому пункту есть свой состав.
#
# Языковая модель на провокацию отвечает охотно и развёрнуто, а зритель,
# который эту провокацию подкинул, ничем не рискует. Рискует владелец
# трансляции. Поэтому дешевле не касаться темы совсем, чем разбираться
# потом, что именно модель сказала.
#
# ЭТО НЕ ОЦЕНКА ЛЮДЕЙ
#
# Здесь перечислены ТЕМЫ, а не «плохие» народы, веры или группы. Слово
# в этом файле означает ровно одно: услышав его, персонаж уходит от
# разговора. Оскорбления лежат отдельно, в blocked_slurs.txt, и караются
# строже — это разные вещи и разные механизмы.
#
# КАК ЧИТАЕТСЯ
#
#   основа       совпадение по НАЧАЛУ слова: "военн" ловит "военный"
#                и "военнослужащий"
#   =слово       точное совпадение целого слова. Нужно там, где основа
#                короткая и лезет в посторонние слова: "=гей" ловит "гей",
#                но не "геймер" и не "гейзер"
#
# Законные слова, которые всё же совпали, добавляются в topic_allow.txt.
# После правки прогоните проверку: python -m tests.filter_lists
